# Class Materials, sharing and permissions

*How-to guide · Resource Files library*

## Why use it

Learners should be able to open your slides and handouts, but never change or delete the copy everyone else relies on. In a class team, the Class Materials folder does this for you.

## Put resources in Class Materials

1. Open Teams and select your class team from the left-hand list.
2. Open the General channel and select Files at the top.
3. Open the Class Materials folder.
4. Select Upload, choose your file, and select Open.
5. Learners can open files in Class Materials, but cannot edit or delete them.

## Check permissions on anything you share elsewhere

1. Before sharing a file, right-click it in OneDrive or Teams and select Share.
2. In the Share window, select the current access level shown, it usually says something like "People in [organisation] with the link" or "Specific people".
3. Choose who the file is for. "Specific people" limits access to named individuals, use this for anything personal or 1:1.
4. Choose the access level for those people: Can view lets someone open and read the file only. Can edit lets them open the file and change it.
5. Select Apply, then select Send or Copy link to share.
6. To check or change permissions on a file that's already shared, right-click the file, select Share, then select Manage access.
7. The Manage access screen lists everyone who currently has access, and whether each person can view or edit.
8. To remove someone's access, select their name, then select Remove or Stop sharing.
9. Once you've removed access, that person's link will no longer open the file.
