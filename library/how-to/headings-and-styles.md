# Headings and styles

*How-to guide · Resource Files library*

This guide is also the text alternative for the short video [headings-and-styles.mp4](../videos/headings-and-styles.mp4), which has no sound.

## The problem

Text made big and bold looks like a heading, but to the computer it is ordinary text. There is nothing to jump to, nothing in the Navigation Pane, and no way to build a contents page.

## Why it matters for learners

- Screen reader users jump from heading to heading. Without headings they hear every word from the top.
- Keyboard users move section by section the same way.
- Immersive Reader, Read Aloud and the Navigation Pane all use headings to show the shape of the document.
- Every learner finds their way around a long workbook faster.

## How to fix it

### In Word

1. Click in the line that should be a heading.
2. Go to **Home**, then **Styles**, then **Heading 1** for the main heading, **Heading 2** for the sections inside it, **Heading 3** below that.
3. Do not skip levels. A Heading 3 should sit inside a Heading 2.
4. Want a different look? Right-click the style, then **Modify**. Every heading changes at once.

### In PowerPoint

Every slide gets a title, in the title placeholder. If a slide should not show a title, keep it and move it off the slide, rather than deleting it.

## Check it

**View**, then tick **Navigation Pane**. Every heading should appear in the list, in the right order. If it is not there, it is not a heading.

Headings done? Add a contents page in one click. See the contents page guide.
