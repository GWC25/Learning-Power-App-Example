# Recording a think-aloud video

*How-to guide · Resource Files library*

## What it is

A think-aloud video is a recording of you narrating your reasoning out loud while working through a task, rather than only showing the finished result.

## Why use it

It makes the reasoning behind a process visible, not only the outcome, which a written record alone can't show. As a video, it can be paused, rewatched or captioned, giving learners more than one way to access the same explanation.

## How to

1. Set up a screen or camera recording (see the Screen recording resource).
2. Work through the task as normal, narrating your thinking and decisions as you go.
3. Pause naturally at key decision points if it helps the explanation land.
4. Stop the recording, add captions if possible, and save it somewhere accessible.
