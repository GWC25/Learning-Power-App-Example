# Setting up channels by topic or unit

*How-to guide · Resource Files library*

## What it is

Channels are the separate sections inside a Teams team, shown as a list on the left-hand side, that split a shared space into smaller, focused areas, for example one channel per topic, unit or week.

## Why use it

A clear channel structure means a learner can go straight to the right topic instead of scrolling through everything at once, and it stays the same shape every time they log in.

## How to

1. Open Teams and select the team you want to organise from the left-hand list.
2. Select the three dots (⋯) next to the team name and choose Add channel.
3. Name the channel after a topic or unit, using the same naming pattern each time, for example "Unit 1, Introduction" rather than only "Unit 1".
4. Choose Standard as the channel type, unless the content genuinely needs to be private to certain learners, in which case choose Private.
5. Select Add to create the channel.
6. Repeat this for each topic or unit, keeping the naming pattern consistent throughout.
7. To reorder channels, select and drag a channel name up or down the list, the most current or important channel is easiest to find near the top.
