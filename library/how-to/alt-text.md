# Alt text

*How-to guide · Resource Files library*

This guide is also the text alternative for the short video [alt-text.mp4](../videos/alt-text.mp4), which has no sound.

## The problem

If a picture carries information, a learner who cannot see it gets nothing. The screen reader says nothing at all, or a file name such as "image005.jpg", or something that tells them nothing, such as "photo of a workshop".

## Why it matters for learners

- Blind and low vision learners using a screen reader.
- Anyone on a slow connection where images do not load.
- Anyone listening to a document read aloud.

Ask: **if the image vanished, would anyone miss anything?** If yes, describe it. If no, mark it decorative.

## How to fix it

1. Right-click the image, then **View Alt Text**. This works in Word, PowerPoint, Excel and Outlook.
2. Write what it tells the learner, not what it shows. One or two sentences.
3. Skip "image of" and "photo of". The screen reader already says it is an image.
4. Only decoration? Tick **Mark as decorative** so it is skipped.
5. A complex diagram or chart? Keep the alt text short and describe it fully in the text on the page.

Do not trust automatically written alt text. Read it, and rewrite it so it says what the learner needs.

## Check it

**Review**, then **Check Accessibility**. Every image without alt text is listed. Fix them from the list.
