# Pinning key posts and resources in a channel

*How-to guide · Resource Files library*

## What it is

Pinning fixes an important post or tab to the top of a Teams channel, so it stays visible and easy to find instead of getting buried under newer posts.

## Why use it

It means a learner can always find the most important resource for a channel, like a key document or a set of instructions, without needing to scroll back through the whole conversation history.

## How to

1. Open Teams and go to the channel containing the post you want to pin.
2. Find the post in the conversation, then select the three dots (⋯) that appear when you hover over it.
3. Select Pin from the menu that appears.
4. The post now stays fixed near the top of the channel, marked with a pin icon, so it's the first thing learners see.
5. To pin a file or resource as its own tab instead, select the + at the top of the channel, choose the file or app, then select Save, the tab stays visible across the top of the channel for everyone.
6. To remove a pinned post, select the three dots (⋯) on it again and choose Unpin.
7. Keep pinned content to genuinely key resources, pinning too many things makes it harder to spot the ones that matter most.
