# Accessibility Checker

*How-to guide · Resource Files library*


Run it before you share anything. It finds the most common problems in a document, slide deck or spreadsheet, and tells you how to fix each one.


## What it is

A tool built into Word, PowerPoint and Excel that checks your file against a set of accessibility rules. It lists what it finds and suggests a fix for each problem.


## Why use it

It is the first of the Super Six, and one of the two every area works towards first. It catches problems that stop a learner using your resource, missing alt text, headings that are not real headings, text that is hard to read against its background, before the learner meets them.

It also comes first for a practical reason. Immersive Reader, read aloud and screen readers all rely on a document being built properly. The checker is how you know it is.


## Before you start

- Open the file you are about to share, and save it.
- Word checks accessibility in the background while you work, and puts a reminder in the status bar at the bottom of the window when it finds something.

## Open the checker


### In the app on a Windows computer, Word, PowerPoint or Excel

1. Open the **Review** tab.
2. Select **Check Accessibility**. If the button is split in two, select the top half. The bottom half gives more options.
3. The **Accessibility** pane opens on the right.

### In the app on a Mac

1. Open the **Review** tab.
2. Select **Check Accessibility**.

### In a browser, Word, PowerPoint or Excel online

1. Open the **Review** tab.
2. Select **Check Accessibility**. The **Accessibility** pane opens on the right.
Outlook on the web works differently and is not covered here.


### If there is no Check Accessibility button

You may have an older version of the app. Select **File**, then **Info**, then **Check for Issues**, then **Check Accessibility**.


## Fix what it finds

Results are grouped by how serious they are:

- **Errors**, content that is difficult or impossible for someone with a disability to read or understand. Fix all of these.
- **Warnings**, content that, in most cases, will be difficult to understand. Fix these too.
- **Tips**, content people can use, but which could be better organised.
1. Select an issue under **Errors** or **Warnings**. The list opens to show every item affected.
2. Select an item. You are taken to it in the document.
3. Select the down arrow next to the item to open **Recommended Actions**.
4. Choose a fix. Some are one click; others open the place where you make the change, such as the Alt Text pane.
5. Work down the list until Errors and Warnings are empty, then save.

## What it cannot tell you

Microsoft is clear that the checker does not catch everything, so always look over your work yourself too. In particular it cannot tell you:

- whether your alt text is any good, only whether it is there
- whether a slide makes sense when read aloud in order
- whether you are relying on colour alone to carry meaning, such as marking correct answers in green
- whether your language is plain enough for the learners in front of you
An empty results list is the floor, not the finish.


## Check it worked

Run the checker again. When the Errors and Warnings lists are empty, the file has cleared the first gate.

Check whether you are in the app or the browser version, and use that section above. If it still does not match, tell the Digital Pedagogy Coach team so this guide can be corrected.
