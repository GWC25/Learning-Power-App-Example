# PowerPoint reading order

*How-to guide · Resource Files library*

This guide is also the text alternative for the short video [reading-order.mp4](../videos/reading-order.mp4), which has no sound.

## The problem

A screen reader does not read a slide the way you look at it. It reads each item in the order it was added to the slide. Add the title last, and the title is read last. Add a "bring your PPE" box at the end, and that is read first.

## Why it matters for learners

- Blind and low vision learners hear the slide as a list, in the wrong order, and have to rebuild it in their heads.
- Learners using Read Aloud or Immersive Reader get the same jumbled order.
- A table read across with no header row loses which column was which.

The slide can look perfect and still be badly built. Designed and built are different things.

## How to fix it

1. Open the slide. Go to **Review**, then the small arrow on **Check Accessibility**, then **Reading Order Pane**.
2. The list shows the order a screen reader will take. **Top of the list is read first.**
3. Drag the title to the top. Then drag the rest into the order you would read them aloud.
4. Decorative pictures can be marked decorative, so they are skipped. Right-click, **View Alt Text**, tick **Mark as decorative**.

### In PowerPoint for the web, or an older version

Use **Home**, then **Arrange**, then **Selection Pane**. It runs backwards: **the bottom item is read first**. Drag the title to the bottom.

## Check it

- Run **Review**, then **Check Accessibility**. Slides with a questionable reading order are listed.
- Better still, use slide layouts with title and content placeholders. They start in the right order.
